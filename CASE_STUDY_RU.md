# DizZy Systems Atlas — описание кейса

## Задача

Объединить большое количество разнородных репозиториев в одну понятную систему, где посетитель сразу видит не количество файлов, а инженерные направления, зрелость проектов и общую логику работы автора.

## Решение

Создан интерактивный технический атлас. Проекты представлены как узлы единого графа и разделены по функциональной роли: backend, платформы, AI/RAG, продукты, автоматизация, data/CV, mobile, edge/voice, quality и digital experiences.

Посетитель может:

- искать проекты по названию, стеку и предметной области;
- фильтровать граф по направлениям;
- переключаться между графом и списком;
- открывать карточку с задачей, архитектурой, стеком и инженерными особенностями;
- переходить в доступный публичный репозиторий;
- отдельно просматривать серию визуальных сайтов.

## Технологии

- HTML5;
- CSS3;
- Vanilla JavaScript;
- Canvas API;
- IntersectionObserver;
- Web Animations API;
- GitHub Actions / GitHub Pages.

## Ключевые решения

- данные проектов вынесены в отдельный файл `scripts/projects.js`;
- интерфейс не зависит от npm, сборщика или CDN;
- Canvas-граф автоматически перестраивается после поиска и фильтрации;
- для сенсорных устройств предусмотрен полноценный list mode;
- закрытые репозитории отображаются как кейсы без неработающей публичной ссылки;
- поддержан `prefers-reduced-motion`.
