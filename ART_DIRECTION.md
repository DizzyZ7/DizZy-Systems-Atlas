# Art direction — DizZy Systems Atlas

## Core idea

A technical observatory rather than a conventional portfolio. Every project is treated as a signal inside one operating field.

## Visual language

- dark graphite and deep blue infrastructure background;
- acid mint as the primary operational signal;
- cyan, pink and yellow accents for system classes;
- mono labels, coordinates, status fields and architecture chains;
- oversized editorial typography for major statements;
- circular topology, crosshairs, scanning lines and structured panels;
- no screenshots required for the baseline experience.

## Motion

- subtle background network generated on Canvas;
- topology nodes float around domain clusters;
- pointer interaction affects the Hero system core;
- filters rebuild the graph without page reload;
- detail drawer behaves like an operator console;
- reduced-motion mode removes continuous animation.

## Mobile behavior

- no hover-only interactions;
- project nodes remain tappable;
- graph can be switched to an accessible list;
- digital experiences use horizontal touch scrolling;
- drawer becomes full width;
- primary navigation uses a full-screen panel.
